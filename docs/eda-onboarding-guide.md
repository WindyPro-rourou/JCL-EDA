# 零基础接入指南：怎么让 AI 在你的「嘉立创 EDA 专业版·在线版」里画图

> 面向 **完全没画过电路图** 的你。跟着做，大约 3~5 分钟就能让 AI 接管你的画板。
> 本指南对应的插件：**dsh-lichuang-eda（嘉立创 EDA 助手）**。
> 技术依据：`docs/eda-backend-research.md`（选型与连接机制，含【待验证】项的诚实标注）。
> 定位：本插件 = **平台层**（装/启/连官方桥 + 提供执行官方 `eda.*` API 的双手 + 校验 + 离线兜底）；**生成电路图 = 在对话里进行（skill 式直觉）**。

---

## 一、核心思路（一句话）

AI 不是"截图猜位置"，而是**通过嘉立创官方 API（WebSocket 桥接）直接在你已经打开的那个画板里放元件、连线、加网络标签，实时画给你看**。

**生成是在对话里进行的（skill 式直觉）**：你对 AI 说"嘉立创EDA，启动！帮我画一个 …"，AI 用 `eda_exec` 逐步执行官方 `eda.*` API（放元件→连线→网络标签→DRC/网表/BOM），在你打开的**云端画板**上实时画，你全程看得见。

所以你只需要做一件事：**把一个「在线专业版」的原理图画板打开，并让插件连上它。** 剩下的一切画图动作由 AI 在对话里完成。

---

## 二、连接画板 =「官方栈」（3 步 · 全部来自嘉立创官方）

> 基于官方 `easyeda-api-skill` 桥（作者 JLCEDA）+ 官方扩展 **Run API Gateway** —— **无任何第三方后端**。

| # | 你手动做什么 | 插件能否自动化 |
|---|---|---|
| ① | **一键安装官方桥**：插件下载官方 easyeda-api-skill 到 `~/.dsh/eda/bridge/` 并装依赖（仅 ws）；桥监听 `127.0.0.1:49620-49629` | ✅ **插件一键**（面板「一键安装官方桥」 / `eda_bridge_install`），你无需操作 |
| ② | **启动官方桥**（bridge-server.mjs，自动选 49620-49629 端口 + health 探测） | ✅ **插件一键**（`eda_backend_connect` / 面板「启动官方桥」）；插件加载时若检测到已装，**自动启动并自动连接** |
| ③ | 在**网页版编辑器**装官方扩展 **Run API Gateway**：打开 `https://pro.lceda.cn/editor` → 顶部菜单**「高级」→「扩展管理器」**（V3：联网可搜索安装；有 `.eext` 可点「导入」）→ 在「已安装」里点该扩展，开启 **「外部交互」** 权限与 **「显示在顶部菜单」**，然后刷新/重开编辑器页面 | 半自动（面板给编辑器/扩展直达链接 + 步骤提示） |

**真正要你手动做的只有第 ③ 步**（在网页版编辑器里装一次官方扩展并勾「外部交互」）；①② 由插件一键完成。

**验证**：面板状态变绿 = 官方桥已连上你的画板；此时 AI 通过 `POST /execute` 执行官方 `eda.*` API（放元件/连线/网络标签/DRC/网表/BOM），你全程看得见。

**兼容性说明（已核实）**：官方文档《扩展的获取和使用》（2026-05 更新）明确给出**网页版**安装路径：`pro.lceda.cn/editor` →「高级」→「扩展管理器」（V3），并支持「外部交互」权限——所以**网页版可用**；此前"仅桌面"的说法以这篇官方文档为准，已修正。

### 持久性说明（每样东西存在哪 / 什么时候要重做）

| 项 | 存在哪 | 要不要重做 |
|---|---|---|
| 官方扩展 Run API Gateway 安装 + 「外部交互」权限 | **随你的嘉立创账号持久** | 一次即可，换设备/浏览器也能用 |
| 官方桥（easyeda-api-skill）安装 | **随你本机磁盘持久**（`~/.dsh/eda/bridge/`） | 装一次即可；插件加载时自动启动 |
| 桥 ↔ 画板的连接 | **每次打开编辑器自动重连** | 需桥在跑（由插件自理），画板页面保持打开即可 |

## 三、为什么这是"门槛最低"的方案

| 你不需要 | 因为 |
|---|---|
| 装桌面客户端 | 全程只是浏览器 + 一个本地小桥接 |
| 申请 API Key / token | 鉴权 = 你浏览器里已登录的账号 + 本机回环(127.0.0.1)白名单 |
| 理解 OAuth / 配置 | 插件不碰你的账号密码，只操作"你打开的那张图" |

| 状态 | 说明 | 你该做什么 |
|---|---|---|
| 🔴 未连接 | 官方桥没起，或没探测到画板 | 确认专业版页面已打开/已登录；确认官方扩展 Run API Gateway 已装且勾了「外部交互」；点面板「一键安装官方桥 / 启动官方桥」 |

| 🟢 已连接 | 官方桥已连上你的画板 | 直接对 AI 说"嘉立创EDA，启动！帮我画一个 …"即可 |

## 五、两种生成方式（对话式为主，离线为兜底）

1. **对话式实时生成（主路径，需要上面 ③ 的连接）**：在 DSH 对话框里对 AI 说"**嘉立创EDA，启动！帮我画一个 …**"，AI 用 `eda_exec` 逐步执行官方 `eda.*` API 在你打开的**云端画板**里**一步一画**：放元件 → 连线 → 网络标签 → 跑 DRC → 导网表/BOM → 转 PCB，你全程看得见。官方文档/样例已随桥 vendored 到 `~/.dsh/eda/bridge/`，AI 先 `read` 再调用。
2. **离线生成（兜底，无需连接画板）**：选模板卡（LED 点亮 / 电阻分压等）或输入中文需求 → 生成**可导入嘉立创 EDA 标准版的原理图 JSON**（结构+连通性校验通过），手动导入后即可编辑/打样。**仅在无法连接画板时使用**；能连上时一律走上面的云端实时生成。

## 六、常见问题（FAQ）

**Q：我没有任何电路基础，真的能画出来吗？**
A：可以。你只需要用中文描述需求（或从模板卡"点菜"），AI 负责放元件、连线、打网络标签。

**Q：画完怎么拿到做 PCB 打样？**
A：AI 可帮你从原理图一键转 PCB（自动摆件 + 布局草案）→ 你微调 → 用嘉立创下单打样。v0 阶段自动布线等高级能力是否限会员会在结果里提示。

**Q：一定要用本地客户端吗？**
A：**不用。** 本方案专门针对**网页版在线专业版**。

**Q：v0 有哪些局限（诚实说明）？**
A：① 离线生成器目前只支持 **电阻 / LED** 两种符号（模板卡里标 ⏳ 的是暂不支持，不会编造）；② 云端实时画板链路需真机验证（见插件 README「不确定/未验证」）；③ 生成的标准版 JSON 能否 100% 无报错导入嘉立创，需你按下一节实测一次。

**Q：这些东西是永久保存的吗？每次用都要重来吗？**
A：官方扩展 Run API Gateway 安装 +「外部交互」权限**随你的嘉立创账号持久**（一次即可）；官方桥**随本机磁盘持久**（`~/.dsh/eda/bridge/`，插件加载时自动启动）；桥 ↔ 画板的**连接每次打开编辑器自动重连**（需桥在跑、画板页面保持打开）。所以你**不用每次重新安装**，只要打开画板并保持页面开着即可。

## 七、第一次实测建议（拿到结果后 30 秒验证）

用离线生成得到 `~/.dsh/eda/output/*.json` 后：
1. 打开**嘉立创 EDA 标准版**（网页版或客户端）；
2. **文件 → 导入**，或按官方文档用「EasyEDA 源文件对话框」**粘贴 Apply**（免导入的自检方式）；
3. 看到元件/导线/网络标签出现在画布上即 ✅。如有报错，把文件发给我们调格式。
